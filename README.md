# Purva Chiniya's website

This is the static site for [purvachiniya.github.io](https://purvachiniya.github.io/).
GitHub Pages serves `index.html` directly.

- Edit `index.html` for website content, including News & Updates.
- Edit `resume/resume.html` and run `bash resume/build.sh` to rebuild the
  PDF used by the **Download CV** link. See [resume/README.md](resume/README.md).
- Conference slides are stored in `slides/` and linked from News & Updates.
