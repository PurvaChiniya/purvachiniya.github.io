# Résumé project

The editable résumé is [resume.html](resume.html). It contains the content and
print layout in one file. The website's **Download CV** button links to the
generated PDF at the repository root.

## Update

1. Edit `resume.html`.
2. Run `bash resume/build.sh` from the repository root. Chrome or Chromium is
   required; set `CHROME_BIN` if it is installed at a custom path.
3. Open `Purva_Chiniya_Resume.pdf` and check that it fits on one page.
4. Commit both the HTML source and PDF so the website serves the current CV.

The source was transcribed from the résumé that was already on this site. Its
contact details, experience, publications, and skills remain editable without
special résumé software.
